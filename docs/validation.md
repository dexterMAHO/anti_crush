# گزارش اعتبارسنجی

بررسی انجام‌شده در ۲۰۲۶-۱۱-۰۸:

- SQLite: پانزده تست موفق؛ سه تست مخصوص قفل PostgreSQL به‌صورت آگاهانه skip شدند.
- PostgreSQL 17 واقعی در کانتینر موقت: هجده تست موفق، بدون skip.
- Ruff lint و format: موفق.
- uv lock --check: موفق.
- ساخت Docker image: موفق.
- Alembic upgrade در دیتابیس خالی، check همخوانی schema، downgrade و upgrade مجدد: موفق.
- pg_dump از داده آزمایشی، رمزگذاری age، رمزگشایی و pg_restore در دیتابیس خالی:
  موفق؛ کاربران، پیام‌ها و audit قابل بازیابی بودند.
- بررسی syntax اسکریپت‌های Bash: موفق.

سناریوها: پذیرش قوانین، تکرار Update، حفظ JSON ورودی و بازخوانی، ناشناس‌بودن
قالب عمومی، مجوز نقش‌ها، callback جعلی، تصمیم قدیمی، بررسی حساس، مالکیت انصراف،
حفظ متن بعد از انصراف، سقف نرخ، محدودسازی/رفع محدودیت، AI timeout و خروجی نامعتبر،
پوشاندن اطلاعات حساس در ورودی AI، بازیابی انتشار نیمه‌تمام، retry محدود،
timeout نامشخص، دو تصمیم هم‌زمان، نرخ هم‌زمان و دو Publisher هم‌زمان.

اتصال واقعی Telegram و سرویس AI خارجی اجرا نشده: توکن/کانال و endpoint عملیاتی
در اختیار پروژه نیست. تست Telegram با transport ساختگی انجام شده است.
پشتیبان آزمایش‌شده شامل داده آزمایشی است؛ استقرار نهایی باید محل مستقل Backup،
زمان‌بندی و تمرین بازیابی اختصاصی خود را داشته باشد.
